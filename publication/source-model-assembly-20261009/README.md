# 실제 소스·모델 경로 연결 관측

컴파일러 `e5be98712f6b435917b297447200ef50e7adb493`와 작업장 구현 커밋
`b327a69`를 깨끗한 상태에서 빌드했습니다. 작업장 체크아웃 밖인 `/tmp`에서
`assemble` 실행 파일을 사용했습니다. 원본은 gzip으로 보관하고 `originals.json`에
압축 전 지문과 바이트 수를 기록했습니다. 압축 해제한 원본의 지문·크기를 대조했습니다.

| 실행 | Gooo가 고른 경로 | 조립 추론 | 별도 호출 사례 | 필드 기대값 | 명령 전체 시간 |
| --- | --- | --- | --- | --- | --- |
| 모델 생략 | fixed | 0회 | 4/4 | 12/12 | 2.51초 |
| 한글 타입·그래프 모델 | model | 1회 | 4/4 | 12/12 | 1.40초 |
| 영문 타입·그래프 모델 | model | 1회 | 4/4 | 12/12 | 1.35초 |
| 선택 하나·그래프 모델 | fixed | 0회 | 4/4 | 12/12 | 1.58초 |

각 행은 같은 네 호출 사례를 사용합니다. 네 행을 합쳐 새로운 16개 사례의 정확도로
표시하지 않습니다. 경로 규칙은 입력 관측을 읽고 새 추론 없이 실행했으며 정답 점수는
0/0입니다. 대상 본문의 조립용 필드 사례와 별도 호출 기대값은 보고서에서 구분합니다.
정수 `9007199254740993`과 음수, 한글, 이모지가 실제 실행 원본에 남습니다.

모든 경로에서 생성 코드 지문과 호출 출력이 저장 재생과 같았습니다.
선택 하나의 원본 사유는 `THREE_FIELD_CHOICES_REQUIRED`입니다. 표현할 수 있는
두 경로는 사전 확인의 모델·입력 지문이 실제 조립 기록과 같았습니다.

`resources.txt`는 macOS의 전체 명령 관측입니다. 사전 확인, Gooo 경로 규칙의 생성·실행,
대상 조립과 저장 재생을 포함합니다. 원본의 최대 RSS는 약 86.7–87.4 MB였습니다.
기기 전체 CPU 사용률이나 동시에 살아 있는 모든 프로세스의 메모리 합을 측정한 자료는
없습니다. 한글·영문 행의 모델 계산 기록은 각각 54,334 ns, 60,917 ns입니다.
실행 순서와 캐시 상태가 같다는 조건은 설정하지 않았습니다. 이 자료는 한 번씩 실행한
사용 흐름의 관측이며 경로 간 속도 비교용 벤치마크로 분류하지 않습니다.

`human-guide.txt`는 같은 고정 경로를 한 번 더 실행해 실제 기본 안내 문구를 저장한
자료입니다. 네 행의 집계에 더하지 않았습니다. `compiler-build.json`과
`workbench-build.txt`에는 실제 소스·Go·SDK 빌드 정보가 있습니다.

확인 명령은 [예제 안내](../../examples/model-assembly/README.md)에 있습니다.
없는 모델과 알 수 없는 상태는 네 성공 행과 별도로 네이티브 테스트에서 검사합니다.
