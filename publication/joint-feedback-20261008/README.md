# 실패 예제를 다음 조립에 반영하기 — 2026-10-08

Gooo로 작성한 규칙이 실패 사례를 고르고, Go 실행부가 입력과 기대값을 그대로
다음 조립 조건에 추가합니다. 모델이 좋은 첫 선택을 못 하더라도 주어진 조건을
더 넣어서 다시 시도할 수 있게 했습니다. 원래 기대값을 수정하는 단계는 없습니다.

## 실제 결과

계획과 예제는 `4e4c958`에서, 실행 구현은 `f391747`에서 먼저 고정했습니다.
공개 Gooo 0.6.12-dev(소스 `4a0cfdd8`)와 기존 자체 그래프 QAT 모델을 사용했습니다.
가중치는 학습하거나 수정하지 않았습니다. 프로그램은 2개, 실행은 4개입니다.

| 프로그램 | 후보 순서 | 회차 | 전체 프로그램 시도 | 추가 사례 | 마지막 평가 |
|---|---|---:|---:|---:|---:|
| 기존 산술 예제 | 기본 | 5 | 16 | 2 | 4/4 |
| 기존 산술 예제 | 자체 모델 | 1 | 1 | 0 | 4/4 |
| 새 요금 계산 | 기본 | 1 | 1 | 0 | 4/4 |
| 새 요금 계산 | 자체 모델 | 5 | 16 | 4 | 4/4 |

요금 예제는 기본 금액, 차감액, 차감 시작 조건의 세 선택지로 구성됩니다.
이 예제에서 모델은 잘못된 조합을 먼저 골랐습니다. 모델이 매 회차 같은 순서를
제안해도, 누적한 반례와 1·2·4·8의 시도 한도 안에서 올바른 조합을 찾았습니다.
산술 예제에서는 모델의 첫 선택이 맞았습니다. 각 프로그램에서 최종 Gooo 소스는
기본 순서와 모델 순서가 바이트까지 같았습니다.

모든 마지막 평가의 입력 4개는 해당 실행의 조립 조건과 겹치지 않았습니다.
9007199254740993처럼 2^53보다 큰 정수도 포함했습니다. 반복 중 사용하는
평가 예제는 선택에 영향을 주므로 적응형 예제로 표시합니다. 마지막 평가 파일은
선택이 끝난 뒤에만 전달했으며, 저장된 조립 기록을 재실행할 때 새 모델 호출은
0회였습니다. 이 소규모 결과로 자연어 전반의 정답률이나 학습 자료와의 독립성을
추정하지 않습니다.

## 시간과 자원 관측

| 프로그램 / 순서 | 조립 명령 시간 합계 | 전체 명령 실시간 | user / sys CPU 초 |
|---|---:|---:|---:|
| 산술 / 기본 | 6.095초 | 10.53초 | 4.90 / 3.53 |
| 산술 / 모델 | 0.556초 | 1.15초 | 0.59 / 0.42 |
| 요금 / 기본 | 0.813초 | 1.48초 | 0.62 / 0.45 |
| 요금 / 모델 | 7.516초 | 11.52초 | 5.14 / 3.72 |

전체 시간에는 Gooo 진단·반례 선택·최종 재실행도 포함됩니다. 조립 명령 시간에는
컴파일과 유한 예제 실행이 포함됩니다. 모델의 예측 자체는 6번 호출에서
28.375–32.875µs였고, 로딩 시간은 별도입니다. 모델이 보고한 텐서 메모리는
2,096바이트입니다. 전체 프로세스의 RAM을 뜻하지 않습니다.

`time -lp`의 최대 RSS는 실행별 87,031,808–88,293,376바이트였습니다.
이 값과 CPU 초는 명령 실행의 OS 관측값이며, 장비 전체의 CPU 사용률 변화는
측정하지 않았습니다. 같은 동안 회귀 테스트도 실행 중이었으므로 시간 수치는
통제된 성능 비교로 사용하기 어렵습니다. 이번에 확인한 것은 첫 선택의 이득과
실패가 모두 존재하며, 실패를 다음 조립 조건으로 전달할 수 있다는 점입니다.

## 재확인

`local-observations.tar.gz`에 원본 실행 결과, 각 회차의 Gooo 소스와 사례,
반례 선택 정책의 결과, 마지막 재실행, 시간 관측을 저장했습니다.
`summary.json`은 원본의 실제 값과 기대값을 다시 세고 만든 요약입니다.
`observed-model.json`과 `model-files.sha256`으로 사용한 모델을 대조할 수 있습니다.

저장소 루트에서 다음처럼 원본을 펼쳐 재집계할 수 있습니다.

```sh
mkdir -p out/feedback-readback
tar -xzf publication/joint-feedback-20261008/local-observations.tar.gz -C out/feedback-readback
go run ./experiments/joint-feedback-observe out/feedback-readback > out/feedback-readback/summary-again.json
cmp publication/joint-feedback-20261008/summary.json out/feedback-readback/summary-again.json
```

재집계 코드는 큰 정수를 그대로 비교하고, 반례 복사 전후의 기대값·해시,
준비한 파일이 다음 회차에 소비됐는지, 마지막 평가의 재실행과 모델 호출 수를
확인합니다. 원본 프로그램의 실행은 컴파일러가 남긴 재실행 기록을 기준으로 합니다.

별도 회귀 테스트에는 서로 모순된 기대값, 중복 행, 여러 출력과 레코드,
행 순서가 바뀐 실행 기록, 입력만 있는 관측, 128행·32KiB 한도, 취소가 포함됩니다.
모순된 요구는 한쪽을 지우지 않고 1/2로 남았습니다.
