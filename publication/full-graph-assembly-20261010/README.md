## 원본과 투영

`summary.json`과 각 `observation.json`은 원본 실행 결과에서 집계한 투영입니다.
각 폴더에는 소스·호출 사례·계획·모델 요청·선택한 반례·마지막 별도 사례가 있습니다.
`assembly.json.gz`, `replay.json.gz`, `saved-composition.json.gz`,
`last-round.json.gz`, `holdout-result.json.gz`는 원본 JSON을 바꾸지 않고 압축한 파일입니다.
해시 목록의 gzip 파일을 풀어 원본 네이티브 결과를 읽을 수 있습니다.
`next-context.json`의 경로는 최초 출력 폴더 기준이며 이 공개 폴더는 작은 증거 묶음입니다.
완전한 실행 출력 폴더를 대신하지 않습니다.

TDD에서 먼저 발생한 실패와 교정 후 검사 로그도 `*.log.gz`로 함께 남깁니다.
빌드 식별 기록은 `workbench-candidate-build.txt.gz`입니다.
압축 전후의 원본 바이트를 비교했으며 로그의 공백과 실패 내용도 보존했습니다.
전체 로컬 검사는 마지막 typed-path 안내 추가 직전에 통과했고,
마지막 집중 경쟁 상태 검사는 추가 후의 코드에서 통과했습니다.
병합을 위한 GitHub CI는 최종 커밋에서 별도로 실행합니다.

선택에 사용한 호출·본문 자체 사례와 마지막 별도 호출은 구분합니다.
모델의 학습 데이터 노출 범위는 이 실행에서 확인하지 않았습니다.
이 결과의 적용 범위는 공개된 작은 예제와 제한한 후보 공간입니다.
