# 최근 사례를 Gooo의 사용 흐름에 연결하기

2026-10-09에 Hacker News, GeekNews와 GitHub Trending에서 사례를 찾고 원문을
읽었습니다. 게시판에서 다시 소개된 시점과 원문 날짜를 구분합니다.
GitHub Go 주간 페이지에는 3주 전 수집 표시가 있어 현재 순위로 인용하지 않습니다.

이 글은 PR51의 도움말 변경 시점 기록입니다. 이후 두 조립 경로를 연결한 내용은
[반례 피드백 후속 구현](research-feedback-2026-10-09.md)과
[construct --assembly 사용 안내](../examples/assembly-feedback/README.md)에 있습니다.

## 이번에 적용한 것

| 사례에서 읽은 원리 | 작업장에 연결한 부분 | 확인 방법 |
| --- | --- | --- |
| 작업에 맞는 작은 진입점 | 첫 도움말에서 시작·결과 읽기·반복 실험의 명령을 찾음 | --help, help 명령, 명령 --help |
| 실행 결과가 다음 선택의 입력 | Gooo가 호출·필드·조립용 사례를 따로 읽어 후속 작업을 제안 | assemble의 report.json과 next-context.json |
| 작은 모델의 입력·출력 범위를 명시 | 조립 전에 모델 입력을 확인하고 소스의 선택지에 연결 | 공개 0.6.22의 body-context --model |

[Addy Osmani의 agent-skills](https://github.com/addyosmani/agent-skills)는 사용자가
하려는 작업과 실행 명령을 함께 보여줍니다. 이 구조를 참고해 작업장의 첫 화면도
‘소스 만들기’, ‘조립하기’, ‘저장된 결과 읽기’에서 시작하도록 구성했습니다.
외부 코드는 가져오지 않고 기존 명령을 안내합니다.

점검 중 assemble 외의 여러 명령에서 --help가 오류로 끝나는 문제를 확인했습니다.
refine과 공통 명령의 도움말도 정상 종료하고, 알 수 없는 명령은 첫 안내로 연결합니다.
도움말을 읽을 때 컴파일러와 모델은 실행하지 않습니다.

[Matt Pocock의 skills](https://github.com/mattpocock/skills)는 프로젝트에서 공유하는
용어와 작은 테스트 피드백을 강조합니다. Gooo의 결과도 ‘조립용 사례’, ‘실제 호출’,
‘저장 재생’을 각각 읽도록 안내합니다. 이번 도움말 변경은 먼저 실패를 재현한 뒤
고치는 순서로 확인했습니다. 개별 단계의 자료에서 전체 구현 확률을 만들지 않습니다.

## 모델 발전에 참고할 것

[Cactus의 Whistle, 10월 2일](https://cactuscompute.com/blog/whistle)은 작은 CPU 모델과
실행 엔진, 명시적인 입력 옵션을 함께 다룹니다. Gooo에는 업무 범위가 작은 모델을
같은 언어 도구 안에 연결하는 원리를 참고합니다. 음성 모델의 크기·속도 수치는
해당 저자의 음성 평가이며 Gooo 모델의 측정값으로 사용하지 않습니다.

현재 작업장은 기존 자체 QAT 모델이 소스의 후보 순서를 제안하도록 사용합니다.
모델을 생략하면 소스 순서로 조립합니다. 알려진 상태를 읽는 경로·후속 판단은
Gooo 조건식으로 실행하고, 선택한 프로그램과 호출 결과를 저장해 다시 씁니다.
새 모델이나 서비스를 설치하는 단계는 이번 사용 흐름에 추가하지 않았습니다.

## 줄인 것과 PR51 당시 다음 실험

도움말의 오류 종료와 긴 명령 목록을 에러에서 반복하는 부분을 줄였습니다.
실행 이유와 결과 위치는 터미널에서 읽고, 전체 그래프는 원본 파일에서 찾습니다.
원본 기대값과 공개 관측은 그대로 유지합니다.

다음은 기존 construct의 반례 피드백과 assemble의 짧은 후속 기록을 함께 쓰는
실험입니다. 새 반복 루프를 추가하기 전에 기존 경로가 받을 수 있는 입력을 확인합니다.
예산 안에서 멈추는 이유, 다음 조립에 실제 사용한 반례와 마지막 독립 평가를 각각
남깁니다. 현재 assemble는 제안과 기록을 만들고, construct는 선언한 평가 사례를
다음 회차에 반영합니다. 두 기능의 연결은 후속 구현 범위입니다.
