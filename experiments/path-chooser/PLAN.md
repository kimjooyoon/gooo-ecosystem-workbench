# A per-choice decision model for this PC

The model receives source-derived typed facts and authored Korean/English
intent. Its output is an existing path label, confidence and possible abstention.
The compiler owns allowed alternatives, finite tests and bounded reconstruction.

## Frozen first experiment

- Existing public Go decision runtime0.2.26; semantic_context_intent_v3 input ABI.
- 256 features,48 hidden values,8 existing path labels:12,728 parameters.
- The same network evaluates every site; this study measures1,2,3,6 and16 sites.
- Six source-derived snapshots from the original compiler426 preflight, with
  source equivalence PASS. The original source, external plan and export are
  copied byte for byte. Conditional input text is distinct from its typed facts.
- 48 authored training utterances and24 different evaluation utterances.
  Both share the same six snapshots and direction words; this is a paraphrase
  study, not general language accuracy or unseen-program evaluation.
- Seed20261010,100 FP32 epochs at.01, then100 additional QAT epochs at.002;
  batch8, one seeded Go CPU process with a five-minute bound.
- Compare FP32, post-training ternary and quantization-aware ternary by loading
  each artifact through the actual SDK. Five trits per byte use1.6 stored bits
  per full matrix group; log2(3) is1.585 entropy bits. Biases remain FP32.

The architecture's fixed shapes imply50,912 FP32 weight bytes and2,759 packed
ternary weight bytes. Ternary tensors occupy12,896 resident bytes, with8 bytes
of matrix scales; each worker's fixed scratch array is1,248 bytes. Metadata,
strings, Go process/runtime and caller receipts add memory beyond those counts.
Local tests check export/load arithmetic, gradient, sizes and zero heap
allocations per PredictInto call. Measured latency and process RSS follow the
actual study; these sizes are not whole-process RAM claims.

## Run

Use a clean committed checkout with Go1.27.2 and a fresh external directory:

```sh
GOWORK=off GOTOOLCHAIN=go1.27.2 go run ./experiments/path-chooser \
  --out /tmp/gooo-path-chooser-study
```

Retain original losses, train/evaluation IDs, model hashes, exact producer and
the1..16-site timing observations. Inference uses one caller-owned workspace
per worker. No tokens, source code, hidden API call or arbitrary alternative is
generated by the decision model.

## Native follow-up

Load the exported model with `body-context --model` to verify representation
and exact input parity, then let `body-codegen` / `body-construct` evaluate the
source-owned cases. Classification and finite function behavior have separate
denominators. Source-bound replay uses zero new inference. This first study's
snapshot corpus does not establish whole-program interactions, program-family
generalization or calibrated probabilities. Those require separate native
and held-out-source observations before compiler integration claims.
